Что указать в DNS

Создайте эти записи в панели регистратора. Имя записи и значение — разные поля.

{% for address in addresses %}

A · {{ binding.hostname }}{{ address }}

{% empty %}

Публичный IPv4 сервера пока не настроен администратором.

{% endfor %}

  1. В TXT вставьте значение целиком, без кавычек. Если панель сама приписывает домен зоны, введите только левую часть имени. Например, для card.example.ru в зоне example.ru: _myqr-verification.card.
  2. A должна вести на указанный IP. Для корня зоны обычно используется @, для card.example.ru — card.
  3. Уберите конфликтующие A, AAAA и CNAME для этого адреса; прокси CDN отключите. Почтовые MX не меняйте. Эта версия подключения рассчитана на IPv4.
  4. Дождитесь обновления DNS и нажмите «Проверить DNS». Сохраните TXT после подключения.
  5. Опубликуйте визитку, подключите Профи и нажмите «Выпустить HTTPS». Когда появится «HTTPS подключён», откройте домен.

Адреса с www и без www подключаются отдельно. Клиентский домен показывает публичные визитки вашего пространства; кабинет и оплата остаются на основном адресе сервиса.
