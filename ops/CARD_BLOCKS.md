# Блоки визитки

Клиент выбирает готовый шаблон и заполняет данные в обычном редакторе
визитки. Там доступны загрузка фона, фото, шапки, фотографий карусели,
PDF и поля для ссылки на видео и адреса. Доступны блоки, включённые
автором шаблона. Незаполненные блоки не выводятся после публикации.
После сохранения черновика клиент публикует визитку.

Визуальный редактор размещения, размеров, значков и оформления блоков
доступен администратору в студии шаблонов `/control/templates`.
Клиент не может открыть его или изменить расположение блоков запросом.

## Карусель

По умолчанию до 10 фотографий. Администратор может изменить лимит
в `/admin/cards/cardblocksettings/` → «Настройки блоков визитки»
(при первом открытии нажмите «Добавить»). Допустимо от 1 до 100.
Уменьшение лимита сохраняет существующие фотографии и опубликованные
визитки; новые фотографии сверх лимита добавить нельзя. Действуют также
лимиты хранилища личного кабинета и ограничения размера каждой фотографии.

## Видео

Поддерживаются HTTPS-ссылки на отдельные видео Рутуб, ВК Видео и Ютуб,
включая короткие ссылки Ютуб и Shorts. Для ВК Видео при необходимости
вставьте также ссылку плеера из «Поделиться → Экспортировать»:
только значение `src`, включая `hash`, без HTML. Ссылка должна относиться
к тому же видео. Закрытые видео, запрет встраивания владельцем или
ограничения доступности самого видеосервиса могут мешать воспроизведению.
Под плеером предусмотрена ссылка для открытия видео на сайте сервиса.

Плееры и карты загружаются только после нажатия посетителя. До этого
браузер не обращается к соответствующему сервису.

## PDF

Один PDF до 10 МБ на блок. Файл выдаётся как вложение для скачивания,
хранится в общем приватном хранилище и учитывается в квоте кабинета.
Доступ посетителям появляется после публикации. Замена в черновике
сохраняет файл текущей опубликованной версии. Файл не исполняется
сервисом; проверка сигнатуры формата не заменяет антивирусную проверку.

На действующем сервере увеличьте размер запроса для сайта (новый образец
`ops/visiooo-https.conf.example` уже содержит `12m`). При стандартном
пути конфигурации проекта:

```bash
sed -i 's/client_max_body_size 6m;/client_max_body_size 12m;/' /etc/nginx/conf.d/myqr-platform.conf
nginx -t && systemctl reload nginx
```

## Карта

Укажите город, улицу и дом. Яндекс Карты выполняют поиск по адресу
в виджете. При неоднозначном результате уточните широту и долготу:
тогда карта показывает конкретную метку. Проверьте точку в режиме
«Предпросмотр» → «Показать карту» перед публикацией.

В шаблонах администратор задаёт расположение и оформление новых блоков;
собственное видео, PDF и адрес клиент добавляет в своей визитке.
