# Редактор клиента

Редактор `/app/cards/<id>/edit` показывает обложку, независимый логотип и
портрет. Данные о себе редактируются по нажатию. Через поиск добавляются
телефоны, почта, ссылки, соцсети и файлы. Первые две кнопки отображаются
квадратами, остальные — строками. Название и адрес каждой кнопки независимы.
Лимит — 30 кнопок. PDF можно загрузить в сервис или указать внешней ссылкой.
Карусель, карта и видео доступны, если соответствующие блоки включены в шаблоне.

Старые телефоны, почта, ссылки и соцсети подставляются в новый редактор.
Само открытие редактора не меняет опубликованную визитку. Новый формат
сохраняется в черновик при сохранении; публикация предварительно сохраняет
актуальные правки и требует отдельного согласия на распространение данных.

В снимке содержимого используются `buttonLayout: "tiles"`, массив `buttons`
с полями `kind`, `label`, `value` и отдельный `logoAssetId`. Номера и ссылки
проверяются сервером; чужие файлы использовать нельзя. PDF без загруженного
файла или ссылки не отображается. Основной телефон и почта остаются в
совместимых полях, дополнительные телефоны включаются в сохраняемый контакт.

Для обновления достаточно штатного `bash ops/deploy.sh`. Зависимости Node
для работы редактора на сервере не нужны. Студия шаблонов администратора
остаётся отдельным редактором оформления.
