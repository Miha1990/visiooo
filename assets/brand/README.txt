Визитка / visiooo.ru — комплект логотипа

Идея: две соединённые карточки образуют букву «в». Яркая точка обозначает новый контакт.
Оригинальный знак создан генератором изображений OpenAI; master PNG 1254 × 1254.

visiooo-logo-master.png — исходник высокого разрешения.
logo-mark-96.png и logo-mark-256.png — знак для сайта и документов.
favicon.ico — значок вкладки, содержит размеры 16, 24, 32, 48, 64, 128 и 256.
favicon-16/32/48/96.png — отдельные значки вкладки.
apple-touch-icon-120/152/167/180.png — значки экрана «Домой» для устройств Apple.
android-icon-192/512.png — обычные значки веб-приложения Android.
android-maskable-192/512.png — значки с безопасными полями для масок Android.

Внешние скругления в файлы не добавлены: на телефоне их применяет система.
Изображения непрозрачные. Важные элементы находятся в безопасной центральной окружности.
На сайте подключён манифест /manifest.webmanifest и ссылки на значки.
Для добавления на iPhone: открыть сайт в Safari, «Поделиться», «На экран Домой».
Для Android: открыть сайт в браузере и выбрать установку или добавление на главный экран.

Повторная сборка из исходника: .venv\Scripts\python.exe ops/build_brand_icons.py
Готовые файлы находятся в app/static/brand, архив — .artifacts/visiooo-brand-kit.zip.
